# CPCT Typing Practice — Free Website

A beginner-friendly static Hindi + English typing practice website.

## Features
- English and Hindi Unicode practice passages
- 1, 5, 10 and 15 minute tests
- Timer, estimated WPM, accuracy and correct-character count
- Responsive layout for desktop and mobile
- No login, database, API key or payment needed

## Run on your computer
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Select language, duration and passage.
4. Press **Start Test** and begin typing.

## Free hosting option: GitHub Pages
1. Sign in to GitHub or create an account.
2. Create a **public repository**, e.g. `cpct-typing-practice`.
3. Upload `index.html`, `style.css`, `script.js`, and this README. Keep the files in the repository root.
4. In repository **Settings → Pages**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Wait for deployment. GitHub will show your published website URL in Settings → Pages.

Alternative: Netlify can publish the folder by using its manual deploy flow. Do not upload secrets or personal information.

## Important
This is an independent practice demo, not an official CPCT website. The score calculation is approximate and is not official CPCT scoring. Hindi typing depends on the Hindi Unicode input method installed on the user's device. A production-grade Remington GAIL/Inscript trainer needs explicit keyboard-layout mapping and extensive testing.
